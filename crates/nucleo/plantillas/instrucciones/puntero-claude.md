Instrucciones para Claude Code

Este archivo solo hace que Claude Code cargue las instrucciones del proyecto, que son las mismas para todos los agentes: AGENTS.md, que escribe Gestor Agentes, y .gestor/instrucciones-del-proyecto.md, que es lo propio de este proyecto. Gestor Agentes reescribe este archivo cada vez que lanza un agente, así que no se escribe nada en él; lo que haya que añadir va en .gestor/instrucciones-del-proyecto.md.
